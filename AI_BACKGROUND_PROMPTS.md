## 🛠️ Tool-Specific Instructions

### DALL-E 3 (ChatGPT Plus)

**How to use:**
1. Copy prompt above
2. Paste into ChatGPT Plus
3. Add: "Generate as pixel art, 1920x1080 resolution, seamless horizontal tiling"
4. Download PNG
5. Import to Godot

**Pro tips:**
- Request "16-bit style pixel art" explicitly
- Specify "seamless horizontal tiling" for parallax
- May need 2-3 attempts to get perfect result
- Use "NO [unwanted element]" to exclude things

---

### Midjourney

**How to use:**
1. Use Midjourney prompts provided above
2. Include `--ar 16:9` for aspect ratio (1920x1080)
3. Include `--tile` for seamless tiling
4. Include `--style raw --v 6` for best pixel art
5. Upscale result to 1920x1080 if needed

**Pro tips:**
- Start with base prompt + parameters
- Use `--no [element]` to exclude (e.g., `--no characters`)
- Can iterate with `/describe` on good results
- Export highest quality PNG

**Parameter guide:**
- `--ar 16:9` = 1920x1080 aspect
- `--ar 16:4.5` = 3840x1080 (wider layers)
- `--ar 16:3` = 5760x1080 (foreground layers)
- `--tile` = seamless wrapping
- `--style raw` = less artistic interpretation
- `--v 6` = latest model version

## 💡 Pro Tips for Best Results

### 1. Seamless Tiling Test
After generation, test seamless tiling:
- Open in image editor
- Duplicate and place side-by-side
- Check for visible seams
- Use "Offset" filter to fix if needed

### 2. Color Consistency
Match colors across layers:
- Jungle: Purple (#6A1B9A, #9C27B0), Green (#2E7D32)
- Dungeon: Dark Grey (#424242), Brown (#5D4037)
- Castle: Red (#B71C1C), Orange (#FF6F00)

### 3. Depth Perception
Ensure proper depth:
- Far layers: Low detail, muted colors, low contrast
- Mid layers: Medium detail, normal colors
- Near layers: High detail, vibrant colors, high contrast

### 4. Transparency
For layering:
- Sky layers: Opaque (no alpha)
- Mid layers: Slightly transparent (90-95% opacity)
- Foreground: Very transparent (70-80% opacity)

### 5. Resolution
Start high, scale down:
- Generate at 2x resolution if possible
- Downscale to target size in image editor
- Apply "Nearest Neighbor" scaling for pixel art
- Sharpen slightly if needed
