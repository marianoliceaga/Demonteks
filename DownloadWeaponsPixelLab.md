## How It Works

1. **Pickup**: Player walks near a `WeaponPickup` → presses **F** → `PlayerCombat.PickupWeapon(type)` is called
2. **Equip**: `PickupWeapon` unlocks + equips the weapon, calls `UpdateWeaponAttackAnimation(type)` 
3. **Damage**: Each weapon already has its own damage value in `PlayerCombat._weapons` — no extra code needed
4. **Animation**: `PlayerController.UpdateAnimation()` reads `_combat.CurrentAttackAnim` for the `AttackState` case. Falls back to `"attack"` (knife) if weapon animation not yet in SpriteFrames

## How to Place Weapon Pickups in Your Levels

1. Open any level scene in Godot
2. Instance `res://Scenes/Items/WeaponPickup.tscn`
3. In the Inspector, set **WeaponToPickup** to:
   - `1` = Machete
   - `2` = Sword  
   - `3` = DemontekSaber
   - `4` = Sawtooth
   - `5` = AlienSword
4. The scene's `Sprite2D` texture can be changed to match the weapon type using the sprites in `Assets/items/weapons/`

## Remaining Steps (Manual in Godot)

When the PixelLab animations complete (run `download_weapon_anims.py` to check + download):
1. Add `attack_sword`, `attack_saber`, `attack_sawtooth`, `attack_alien` animation entries to `Player.tscn` SpriteFrames following the same pattern as `attack_machete`
2. Place weapon pickups in Level 1 or 2 for testing
3. Play the game and pick up a weapon → verify attack animation changes
